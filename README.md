# 🚀 365 Days of GeeksforGeeks — Problem of the Day Challenge

> **One problem a day. One step closer to mastery.**

This repository documents my daily GeeksforGeeks Problem of the Day (POTD) journey. The goal is to strengthen Data Structures and Algorithms, build consistency, and improve my ability to solve unfamiliar problems with clean and efficient C++.

## 🎯 The Mission

- Solve the GeeksforGeeks Problem of the Day consistently.
- Understand the statement, constraints, and examples before coding.
- Identify the right DSA pattern and develop an efficient approach.
- Write clean, readable, optimized C++ solutions.
- Document intuition, dry runs, edge cases, and complexity.
- Learn from mistakes and improve every day.

## 🧠 Daily Workflow

1. **Understand** — Read the problem, constraints, and examples carefully.
2. **Think** — Identify the relevant DSA pattern.
3. **Solve** — Implement the solution and test edge cases.
4. **Optimize** — Analyze time and auxiliary space complexity.
5. **Reflect** — Record the key concept and lesson learned.

## 📁 Repository Structure

Solutions are organized by year, month, and day. Each problem has its own folder containing an explanation and C++ implementation.
